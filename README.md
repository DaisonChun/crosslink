## Installing

1. Connect your Xteink X4 to your computer via USB-C and wake/unlock the device.
2. Go to [https://crosslink-reader.top/](https://crosslink-reader.top:666/) and click "Save full flash" to back up the original firmware.
3. Download and select the crosslink_x4_full_flash_20260522.bin file from the Release, then click "Write full flash from file" to overwrite your device’s entire flash.
4. Note: The partition table of CrossLink is different from other firmware. If you need to flash other firmware later, you must first select the backup firmware from Step 2 and use "Write full flash from file" to restore the original partition table.
